# visual identity 1.2: one integrated hearth wordmark

13 September 2026 UTC. The user requested that the fireplace replace the first h whenever the logo and name appear together, and that the product name always be lowercase.

The combined signature contains the fireplace symbol followed by the existing `earth` letter paths. Their baseline and stroke weight are aligned. It contains no second leading h and no separate icon-to-wordmark gap. Standalone symbols and the standalone text wordmark remain available for contexts that use only one of them.

The active guide and repository instructions now require lowercase `hearth` in product copy, titles, accessibility labels and future prose, even at sentence starts. Copy updates preserve technical header names, environment variables, existing filenames and user-authored text. The original supplied design snapshot remains intact.
