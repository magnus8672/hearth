A certificate warning in Zen or Firefox?

After importing the certificate, wait a moment and check again. Some browsers pick up Windows trust on the next connection. If needed, fully quit and reopen the browser, then rerun Start-Hearth.ps1.

If the warning remains, import this Hearth certificate in the browser’s Settings → Privacy & Security → Certificates → View Certificates → Authorities. Confirm the fingerprint above and allow it to identify websites. Do not add a website exception.

This downloads only the public certificate. Importing it is your separate browser trust decision.
