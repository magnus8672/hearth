01 · RECOGNIZE YOUR hearth

Trust this hearth.

Download its public root certificate, then import it as a trusted certificate authority. A download alone does not install trust.

Install certificate on WindowsDownload certificateWindows certificate (.cer)Full certificate package

On Windows, download and run the installer, check the fingerprint with your administrator, then confirm installation. It trusts this root for your Windows account only. On other systems, import the downloaded root into your browser or system trust store.

Check the certificate fingerprint

Compare this SHA-256 fingerprint with the one printed in your VM console or retrieved over your trusted SSH connection.

@@FINGERPRINT@@
Import in Zen or Firefox

Open Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import. Choose the downloaded hearth-root.crt and allow it to identify websites.

If you trusted it through Windows but Zen still shows SEC_ERROR_BAD_SIGNATURE, fully quit and reopen Zen, then check again. If it persists, import this exact root in Zen’s Authorities tab. Your old laptop hearth uses a different root certificate.

For Chrome or Edge on Windows, import the .cer file into Trusted Root Certification Authorities for your Windows account, then reopen the browser if needed.

A web page cannot automatically install trusted certificates. Keep certificate checking enabled; you do not need a website exception.
